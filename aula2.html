  • Estuda preços e volumes históricos

  • Estuda balanços, DRE e DFC da empresa

✦ Como Buffett une as duas
Buffett usa fundamentalismo para identificar o valor e espera que o mercado (técnica) eventualmente confirme esse valor no preço. A IA acelera a parte fundamentalista — a paciência continua sendo humana.
// fundamentalista · roe · indicador detalhado

ROE — Construindo do Zero com Dados da CVM

// Definição e Fórmula
ROE = Lucro Líquido ÷ Patrimônio Líquido

O que mede: quanto de lucro a empresa gera para cada R$1 de capital dos acionistas. ROE de 20% significa que para cada R$100 investido, a empresa lucra R$20.

// Buffett e o ROE

Buffett exige ROE consistentemente acima de 15% por 10 anos como critério mínimo — mais importante que qualquer pico isolado. É consistência, não magnitude pontual.

⚠ Limitação do ROE
Empresas muito endividadas podem ter ROE alto artificialmente — o PL fica pequeno com a alavancagem. Sempre analise junto com Dívida/PL.

// Valor Intrínseco

O que os fundamentos dizem

Estimativa do valor "real" via DCF ou modelo de Gordon. Independe da cotação — é quanto vale pelos fluxos futuros.

Calculado via DCF + parâmetros RF
Preço > Intrínseco
Ação sobrevalorizada — mercado paga mais do que vale. Sinal de cautela para compra.
Preço ≈ Intrínseco
Ação precificada corretamente — mercado reconhece o valor. Neutro.
Preço < Intrínseco
Ação subvalorizada — oportunidade segundo Graham e Buffett. "Margem de segurança."
// valuation · modelo de gordon (1956)

Modelo de Gordon — A Base Teórica do DCF

// Origem

Myron Gordon publicou em 1956 o Gordon Growth Model — um dos pilares do valuation moderno. Parte de uma ideia simples: o valor de uma ação é o valor presente de todos os dividendos futuros.

P = D₁ ÷ (Ke − g)
// Componentes
PValor intrínseco por ação
D₁Dividendo esperado no próximo período
KeCusto do capital próprio (CAPM)
gTaxa de crescimento perpétuo dos dividendos
// CAPM — Calculando o Ke
Ke = Rf + β × (Rm − Rf)
RfTaxa livre de risco (SELIC/Tesouro)
βBeta — sensibilidade ao mercado
Rm − RfPrêmio de risco do mercado
// Onde IA entra — o diferencial
  • Beta: estimado via Random Forest com fundamentals — mais estável que regressão simples
  • g: intervalo probabilístico via histórico — não uma suposição fixa
  • D₁: projetado a partir do payout histórico × LPA previsto pelo RF
⚠ Limitação central do modelo
Gordon funciona bem para empresas maduras com dividendos estáveis (Itaú). Para empresas de alto crescimento ou sem dividendos regulares (ciclo de commodities como Vale), o DCF com FCFE é mais adequado.
// valuation · dcf com fcfe

DCF com FCFE — Valuation para as 3 Empresas

  • FCFE (Free Cash Flow to Equity): caixa disponível aos acionistas após capex e dívidas
  • FCFE = Lucro Líquido + Depreciação − ΔCapital de Giro − Capex + Variação da Dívida
  • Projeção: FCFE cresce à taxa histórica por N anos e depois a g terminal
  • Desconto: cada FCFE futuro é trazido a valor presente pelo Ke
  • Valor terminal: representa o valor da empresa após o horizonte de projeção
V = Σ FCFE_t/(1+Ke)^t + [FCFE_N × (1+g)] / [(Ke−g) × (1+Ke)^N]

Random Forest — Intuição Financeira

  • Árvore de decisão: fluxograma de perguntas Sim/Não sobre os indicadores — "ROE > 15%? Se sim, vai para a próxima pergunta..."
  • 500 analistas virtuais: o RF cria 500 árvores, cada uma vendo uma amostra diferente dos dados históricos
  • Decisão final: votação — se 380 das 500 árvores dizem "LPA vai crescer", a probabilidade é 76%
  • Não-linearidade: ROE alto combinado com baixa alavancagem é muito mais poderoso que qualquer um isolado — algo que regressão linear não captura
✦ Conexão direta com nossos indicadores
As features do RF são exatamente os indicadores que acabamos de calcular: ROE (3.11/2.03), Margem (3.11/3.01), Dívida/PL (BPP), Cresc. Receita (3.01 YoY) e LPA (3.99).

Random Forest vs XGBoost — Por que Escolhemos RF

// Random Forest · Paralelo

Árvores Independentes

  • Treina N árvores em paralelo, cada uma com amostra aleatória
  • Robusto a outliers e dados irregulares
  • Menos sensível a hiperparâmetros
  • importance() direta e interpretável
  • ✓ Nosso caso: dados da CVM têm outliers e lacunas
// XGBoost · Sequencial

Árvores em Cadeia

  • Cada árvore corrige os erros da anterior (boosting)
  • Geralmente mais preciso em grandes volumes
  • Mais sensível a overfitting
  • Requer ajuste fino de hiperparâmetros
  • → Aula 3: extensão natural para comparar
✦ Por que RF para o beta também?
O beta tradicional é calculado com regressão de 3 anos — muito sensível ao período escolhido. O RF usa ROE, alavancagem e setor para estimar um beta estruturalmente mais estável, menos dependente do ciclo de mercado.
⚠ Limitação dos dois modelos
Ambos aprendem padrões do passado. Mudanças estruturais (nova regulação, fusão, crise) não estão nos dados históricos. A validação humana continua essencial.

Feature Engineering — Calculando os Indicadores

// r · feature engineering completo
library(tidyverse)

calcular_indicadores <- function(dados, ticker) {
  dre <- dados$DRE ; bpp <- dados$BPP ; dfc <- dados$DFC_MD

  receita <- dre |> filter(CD_CONTA=="3.01") |> select(ano=DT_FIM_EXERC, receita=VL_CONTA)
  lucro <- dre |> filter(CD_CONTA=="3.11") |> select(ano=DT_FIM_EXERC, lucro=VL_CONTA)
  lpa_raw <- dre |> filter(CD_CONTA=="3.99") |> select(ano=DT_FIM_EXERC, lpa=VL_CONTA)
  pl <- bpp |> filter(CD_CONTA=="2.03") |> select(ano=DT_FIM_EXERC, pl=VL_CONTA)
  pc <- bpp |> filter(CD_CONTA=="2.01") |> select(ano=DT_FIM_EXERC, pc=VL_CONTA)
  pnc <- bpp |> filter(CD_CONTA=="2.02") |> select(ano=DT_FIM_EXERC, pnc=VL_CONTA)

  receita |> left_join(lucro,by="ano") |> left_join(pl,by="ano") |>
    left_join(pc,by="ano") |> left_join(pnc,by="ano") |>
    left_join(lpa_raw,by="ano") |>
    arrange(ano) |> mutate(
      ticker = ticker,
      roe = lucro / pl,
      margem = lucro / receita,
      divida_pl = (pc + pnc) / pl,
      cresc_receita= (receita / lag(receita)) - 1,
      cresc_lpa = (lpa / lag(lpa)) - 1
    )
}

df <- bind_rows(
  calcular_indicadores(dados_petr4, "PETR4"),
  calcular_indicadores(dados_vale3, "VALE3"),
  calcular_indicadores(dados_itub4, "ITUB4")
)

library(randomForest)

# Preparar dataset com target binário
df_modelo <- df |> filter(!is.na(cresc_lpa)) |>
  mutate(
    target = as.factor(if_else(cresc_lpa > 0.10, 1, 0)),
    ticker = as.factor(ticker)

                cresc_receita, lpa, ticker)

# Treinar com 500 árvores
set.seed(2026)
modelo_rf <- randomForest(
  target ~ ., data = df_modelo,
