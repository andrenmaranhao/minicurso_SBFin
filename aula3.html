// conceitos · o que é um agente

O que é um Agente de IA?

  • Definição: sistema que recebe um objetivo e decide autonomamente quais ferramentas usar, em que ordem, para atingi-lo
  • Diferença do chat: no chat você dá os passos. No agente você dá o destino
  • Loop básico: Perceber → Planejar → Agir → Observar resultado → Repetir
  • Ferramentas típicas: executar código, ler arquivos, acessar APIs, navegar na web, escrever relatórios
  • Hoje (2026): Cursor Agent, Claude Code, GitHub Copilot Agent, ChatGPT Operator
// Chat vs Agente
ChatAgente
Você dá os passosVocê dá o objetivo
Uma resposta de textoPipeline de ações
Sem memóriaContexto persistente
Sem execuçãoExecuta código e APIs
Você valida tudoEle valida parcialmente
⊹ Analogia financeira
Chat = analista que responde quando você pergunta. Agente = analista que recebe a carteira, define o processo e entrega o relatório — você só aprova no final.

// conceitos · orquestração

Orquestração — Agentes Trabalhando Juntos

  • Orquestrador: agente que recebe o objetivo e distribui tarefas para sub-agentes especializados
  • Sub-agentes: cada um especialista em uma coisa — coleta, análise, relatório
  • Comunicação: via arquivos JSON, variáveis de ambiente ou passagem direta de contexto
  • Cuidado: erros em cascata — se o agente de coleta falha, os demais falham também
⚠ Regra de ouro para agentes
Comece pequeno. Automatize uma tarefa de baixo risco por 2 semanas. Valide os resultados. Só então expanda. Nunca automatize o que você não entende manualmente.

O Código que o Agente Gera

// python · agente_preco.py · gerado pelo cursor
# Agente gerado pelo Cursor — IA Aplicada a Finanças · SBFin 2026
import yfinance as yf
from datetime import datetime

def analisar_acao(ticker: str) -> dict:
  # Baixar dados
  acao = yf.Ticker(ticker)
  hist = acao.history(period="5d")
  preco_atual = hist["Close"].iloc[-1]
  preco_inicio = hist["Close"].iloc[0]
  variacao = (preco_atual - preco_inicio) / preco_inicio * 100

  # Classificar
  if variacao > 1: sinal = "📈 ALTA"
  elif variacao < -1: sinal = "📉 QUEDA"
  else: sinal = "➡ ESTÁVEL"

  return {"ticker": ticker, "preco": preco_atual,
           "variacao_pct": variacao, "sinal": sinal}

# Executar para as 3 empresas
for t in ["PETR4.SA", "VALE3.SA", "ITUB4.SA"]:
  r = analisar_acao(t)
  print(f"{r['sinal']} {r['ticker']}: R$ {r['preco']:.2f} ({r['variacao_pct']:+.1f}%)")

// python · buscar notícias com yfinance
import yfinance as yf
import anthropic

def buscar_noticias(ticker: str, n=5):
  acao = yf.Ticker(ticker)
  noticias = acao.news[:n]
  return [
    {"titulo": n["content"]["title"],
     "resumo": n["content"].get("summary","")}
    for n in noticias
  ]

def analisar_sentimento(ticker, noticias):
  client = anthropic.Anthropic()
  textos = "\\n".join([n["titulo"] for n in noticias])
  resp = client.messages.create(
    model="claude-opus-4-5",
    max_tokens=300,
    system="Analise o sentimento das notícias. Responda: sentimento geral (Positivo/Negativo/Neutro), evento principal e nível de relevância (Alto/Médio/Baixo).",
    messages=[{"role":"user", "content": f"Empresa: {ticker}\\n{textos}"}]
  )
  return resp.content[0].text

MCP — O que é e por que importa

  • MCP: Model Context Protocol — padrão aberto criado pela Anthropic para conectar LLMs a ferramentas externas de forma padronizada
  • Analogia: como o USB para dispositivos. Antes do USB, cada fabricante tinha seu conector. MCP é o USB dos agentes — qualquer modelo conecta a qualquer ferramenta
  • O que permite: o LLM decide sozinho qual ferramenta chamar, com quais parâmetros, e usa o resultado para responder
  • Por baixo dos panos: é exatamente isso que o Cursor, Claude Desktop e ChatGPT fazem quando executam código ou acessam arquivos
  • Hoje: implementaremos o conceito completo de MCP usando só Python + SDK da Anthropic — sem instalar mais nada
// O loop do MCP
Você → envia objetivo ao LLM
  ↓
LLM → decide qual ferramenta usar
  ↓
Ferramenta → executa e retorna dados
  ↓
LLM → processa o resultado
  ↓
Você → recebe a resposta final
✦ Por que implementar do zero?
Ver o mecanismo real — o LLM escolhendo ferramentas — é mais didático do que usar um servidor pronto. E com o SDK da Anthropic você já tem tudo instalado.

// python · mcp_financas.py · parte 2 — execução
# ── Implementação das ferramentas ───────────────
def obter_preco(ticker):
  hist = yf.Ticker(ticker).history(period="5d")
  atual = hist["Close"].iloc[-1]
  inicio = hist["Close"].iloc[0]
  return {"preco": round(atual,2),
           "variacao_pct": round((atual-inicio)/inicio*100,2)}

def calcular_indicadores(ticker):
  dre = pd.read_csv(f"dados_cvm/{ticker}_DF Consolidado - Demonstração do Resultado.csv")
  rec = dre[dre["CD_CONTA"]=="3.01"]["VL_CONTA"].iloc[-1]
  ll = dre[dre["CD_CONTA"]=="3.11"]["VL_CONTA"].iloc[-1]
  return {"margem": round(ll/rec*100,1)}

# ── Loop do agente ──────────────────────────────
def executar_ferramenta(nome, params):
  if nome == "obter_preco":
    return obter_preco(params["ticker"])
  elif nome == "calcular_indicadores":
    return calcular_indicadores(params["ticker"])

client = anthropic.Anthropic()
msgs = [{"role":"user",
           "content":"Analise PETR4.SA: preço atual e margem líquida"}]

while True:
  resp = client.messages.create(
    model="claude-opus-4-5", max_tokens=1024,
    tools=TOOLS, messages=msgs
  )
  if resp.stop_reason == "end_turn": break
  # LLM pediu uma ferramenta — executar
  for bloco in resp.content:
    if bloco.type == "tool_use":
      resultado = executar_ferramenta(bloco.name, bloco.input)
      msgs += [
        {"role":"assistant","content":resp.content},
        {"role":"user","content":[{"type":"tool_result",
          "tool_use_id":bloco.id,
          "content":json.dumps(resultado)}]}]

print(resp.content[-1].text)
// O que acontece ao executar
  1. Você envia: "Analise PETR4.SA: preço e margem"
  2. LLM decide: chama obter_preco("PETR4.SA")
  3. yfinance retorna: preço e variação
  4. LLM decide: chama calcular_indicadores("PETR4")
  5. CSV retorna: margem líquida
  6. LLM integra tudo e responde em português
✦ Isso é MCP em essência
LLM + ferramentas externas + loop de decisão. O padrão MCP formal só padroniza como esse loop é exposto — o mecanismo é exatamente este.
