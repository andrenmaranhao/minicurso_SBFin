Se não queremos nos perder nessa massa impressionante de dados estatísticos, precisamos da guia e ajuda de um poderoso arcabouço teórico." — Ragnar Frisch, Econometrica 1(1): 1-4, 1933
⊹ Provocação
Escrito há mais de 90 anos. Na era dos LLMs, o risco de dados sem teoria é maior do que nunca — e mais sedutor. Modelos que "parecem entender" podem estar apenas interpolando ruído com confiança.

✦ A Aposta de Hayek
Em ambos os campos, Hayek discordava profundamente: nem o cérebro nem a economia funcionam com um "controlador central". A inteligência, em ambos, é distribuída e emergente.
// hayek · the sensory order (1952)

O Livro que Ninguém Leu — e Estava Certo

  • O cérebro não funciona como um computador central
  • A mente emerge da interação de múltiplos neurônios
  • Percepção é classificação — o cérebro nunca acessa a realidade diretamente
  • Conhecimento é distribuído e tácito
  • Ordem emerge de interações locais, sem comando central
⊹ Antecipações
Conexionismo · Redes Neurais · Aprendizado Distribuído · Emergência · Plasticidade Neural · Processamento Paralelo

Hayek era conhecido como economista — poucos psicólogos levavam um economista a sério. As ferramentas computacionais da época eram insuficientes para testar suas ideias.

// fundamentos · representação matricial

Tudo é Matriz

  • Imagens: matriz de pixels — 32×32×3 = 3.072 números
  • Sons: séries temporais de amplitude
  • Texto: vetores de embedding em espaços de centenas de dimensões
  • LLMs: probabilidades sobre vocabulário de ~50.000 tokens
TUDO → matrizes de números reais
// Escala

GPT-4: ~1,8 trilhão de parâmetros


Uma frase de 50 palavras com embeddings de 768 dimensões = matriz 50×768 = 38.400 valores


Uma imagem HD 1920×1080 em RGB = 6.220.800 números

// llms · definição

O que são LLMs?

  • Tokens: unidades básicas — palavras, subpalavras ou caracteres
  • Embeddings: representações vetoriais em espaço de alta dimensão
  • Treinamento: bilhões de textos — livros, artigos, código, web
  • Objetivo: prever o próximo token dado um contexto
P(token_{t+1} | token_1, ..., token_t) = f_θ(contexto)
⚡ Insight Central
LLMs são preditores de próxima palavra. "Inteligência" emerge como subproduto de prever linguagem em escala massiva — exatamente a intuição hayekiana de ordem emergente.

// llms · arquitetura transformer

Por que Transformers? (2017)

  • Antes: RNNs e LSTMs — dificuldade com dependências longas
  • Solução: mecanismo de atenção — cada palavra "olha" para todas
  • Multi-Head: múltiplas "cabeças" em paralelo
  • Posição: embeddings posicionais codificam a ordem
Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V
// Encoder

Embedding + Posição → Self-Attention → Feed-forward → Representação contextualizada

// Decoder

Masked Self-Attention → Atenção sobre Encoder → Feed-forward → Próximo token

// llms · limitações

Alucinações: "Mentindo com Confiança"

  • Causa: contextos matricialmente próximos mas semanticamente distintos
  • O modelo interpola: gera texto plausível mesmo sem fundamento
  • Citações e datas: podem ser completamente fabricadas
  • Cálculos encadeados: erros se propagam com aparência de certeza
⚠ Definição
Alucinação: resposta factualmente incorreta apresentada com tom confiante e legítimo. O modelo é treinado para gerar texto plausível — não necessariamente verdadeiro.
⊹ Solução
RAG (Retrieval Augmented Generation): buscar fontes externas e injetá-las no contexto antes de gerar a resposta.
// llms · pipeline completo de inferência

Como LLMs Geram Texto: O Pipeline Completo

// 1–3 · Entrada

Input → Tokenizer (quebra em tokens com IDs) → Embedding Layer (vetores d=4096)

// 4 · Transformer Block

Multi-Head Self-Attention com KV Cache → Feed-Forward Network → Add & LayerNorm (×96 camadas no GPT-4)

// 5–7 · Geração

Linear + Softmax → Probabilidades sobre 128K tokens → Sampling (Greedy, Top-K, Nucleus, Temperature)

// 8–9 · Saída

Detokenizer converte IDs de volta em texto → Streaming token a token para o usuário

✗ Prompt Ruim
Os juros subiram. O que acontece com uma empresa endividada? Faça uma análise e diga se a ação deve cair.

✓ Prompt Bom
Use apenas os dados abaixo. Não busque informações externas.

Dados: dívida R$1,2bi; caixa R$200M; 70% pós-fixado ao CDI; CDI sobe de 11% para 13%; EBITDA R$280M.

Tarefa: 1) calcule o aumento da despesa financeira; 2) estime o novo lucro; 3) calcule dívida líquida/EBITDA; 4) liste as limitações.

Random Forest para Previsão de Crescimento de LPA

// Features de Entrada
  • ROE — retorno sobre patrimônio
  • Margem líquida
  • Endividamento (dívida/PL)
  • Crescimento da receita (12m)
  • Índice P/L
  • Setor de atuação
// Target (Alvo)

Variável binária: 1 se LPA cresceu > 10% nos próximos 12 meses, 0 caso contrário.

// Por que Random Forest?
  • Não-linear: captura interações complexas entre indicadores
  • Interpretável: importance() mostra o que mais importa
  • Robusto: não sofre com outliers nos dados contábeis
  • Rápido: treina em segundos no R
✦ Insight esperado
O modelo identificará que alta margem + baixo endividamento combinados predizem crescimento de LPA melhor que qualquer indicador isolado — algo que análise tradicional não captura facilmente.

Extraindo Dados das 3 Empresas — Python

Peça ao Cursor: "Baixe os dados históricos de PETR4.SA, VALE3.SA e ITUB4.SA dos últimos 3 anos, calcule o retorno acumulado normalizado (base 100) e plote as três séries no mesmo gráfico com o IBOVESPA."

// python · yfinance + pandas + matplotlib
import yfinance as yf
import pandas as pd
import matplotlib.pyplot as plt

# Empresas + benchmark
tickers = ["PETR4.SA", "VALE3.SA", "ITUB4.SA", "^BVSP"]
nomes = ["Petrobras", "Vale", "Itaú", "IBOV"]

# Baixar preços de fechamento ajustados
raw = yf.download(tickers, period="3y")["Close"]
raw.columns = nomes

# Retorno acumulado — base 100
ret = (raw / raw.iloc[0]) * 100

# Visualização
cores = ["#00c8ff", "#00ffb3", "#7b2fff", "#ffb347"]
fig, ax = plt.subplots(figsize=(12, 5))
for col, cor in zip(ret.columns, cores):
  ax.plot(ret.index, ret[col], label=col, color=cor, linewidth=1.8)
ax.axhline(100, color="#3a4a6a", linestyle="--", linewidth=0.8)
ax.set_title("Retorno Acumulado — Base 100 (3 anos)")
ax.legend() ; ax.grid(alpha=0.15)
plt.tight_layout() ; plt.show()
